# Markdown → Word 変換ツール

**バージョン 0.1.0｜Windows 11 / Python 3.13｜完全ローカル**

Markdownファイルまたは直接貼り付けた文章から、**編集可能なWord（.docx）**を生成する独立したデスクトップアプリです。職務経歴書向けの日本語レイアウトと自然な改ページを重視しています。求人比較ツールのブルー系デザインを参考にした、固定ヘッダー・固定フッターと3ステップの1画面UIを採用しています。既存リポジトリとは独立して動作します。

## 主な機能

- `.md` / `.markdown` / `.txt` をUTF-8（BOM可）で読み込む、またはテキストを直接貼り付ける
- `職務経歴書` / `標準文書` の2スタイル
- 見出し、段落、太字、斜体、リンク、リスト、表、区切り線、改行をWordの編集可能な要素へ変換
- 職務経歴書では先頭のタイトル・日付・氏名、`■`見出し、`①`等の小見出し、`【主な業務】`を解釈
- 会社情報・スキル情報の2列データに加え、列数がそろった2行以上の一般タブ区切りデータも表へ変換（職務経歴書スタイル）
- 3ステップ画面の事前確認（文字数・見出し数・表数・箇条書き数・警告）。画面幅に応じて指標の表示列数を調整
- 同名ファイル時は「置換」「別名」「キャンセル」を選択。既存出力を生成前に削除しない
- Word関連付けアプリで開く、保存先を開く（Windows）

## Windows 11で使う（EXE配布版）

1. [GitHub Releases](https://github.com/yonegen0/create_officialpapers/releases) またはWindows配布ワークフローから取得した `MarkdownToWord-0.1.0-win-x64.zip` を展開します。
2. `MarkdownToWord\MarkdownToWord.exe` をダブルクリックします。
3. **STEP 1：Markdownを入力** — ファイルを選択するか、文章を直接貼り付けます。
4. **STEP 2：Wordの出力設定** — 文書スタイル、ファイル名、保存先を設定します。
5. **STEP 3：事前確認・Word生成** — 「事前確認」で4指標と警告を確認し、「Wordを生成」を押します。
6. 生成後は「Wordを開く」「保存先を開く」から確認できます。ヘッダーと処理状態・進捗のフッターは固定で、中央の3ステップをスクロールできます。

> 配布物はWindows上で `build_release.bat` または手動のGitHub Actionsで生成します。Windows 11実機での動作確認は別途必要です。

## ソースから起動

Windows 11 x64 / Python 3.13と、標準搭載のTkinterが必要です。

```bat
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-win11.lock
.venv\Scripts\python.exe -m markdown_to_word.gui
```

入力方式を切り替えても選択したファイルと貼り付け本文は保持されます。入力・文書スタイルを変更すると事前確認が無効になりますが、保存先や出力ファイル名の変更では無効になりません。再度生成するまで前回生成したファイルの参照も残ります。

入力ファイルの文字コードはUTF-8です。BOM付きUTF-8、WindowsのCRLFを受け付けます。Wordのインストールは**生成には不要**です。Wordを開く操作には、`.docx`に関連付けられたアプリが必要です。

## 変換できる記法

- `#` / `##` / `###` による見出し
- `**太字**`、`*斜体*`、Markdownリンク
- `-` / `*` と `1.` / `3.` などによるリスト（開始番号と独立リストの番号を保持、深さ3までの基本スタイル）
- `| 見出し | 見出し |` のMarkdown表
- 明示的な改行・`---`・インラインコード・コードブロック（文字列として保存）
- 職務経歴書スタイル限定：`■` / `①～⑳` / `【主な業務】` / 職務経歴内の「一般事務・受付（2023年10月～現在）」形式 / 文末の「以上」 / 先頭のタイトル・日付・氏名
- 職務経歴の職種見出しは従来の `### 受付・一般事務` や `### 営業` を使用できます。番号付きでも期間が明確なら `### ① 受付（2023年4月～現在）` を職種として扱います。曖昧な職種名に限り任意で `### 職種：受付業務` と明示できます（Wordの職種欄は「受付業務」）。丸数字のみの見出しや「主な成果」「工夫した点」などは職種内の小見出しとして保持します。
- 職務経歴書スタイル限定：`勤務先 / 在籍期間 / 雇用形態 / 事業内容 / 会社規模` の2列連続行、`経験・能力　内容`を見出しとするスキル2列表

- 画像記法 `![説明](path "title")` は画像を埋め込まず、記法を文字列として保持して事前確認で通知します。画像のダウンロードは行いません。

**注意：** 職務経歴書専用の簡易表は、タブまたは**全角スペース**で区切られた、連続した行で指定してください。普通の文章に含まれる半角スペースの数だけで表化はしません。認識できない形式は基本的に文章のまま残します。

## Wordのレイアウト

**職務経歴書**は同梱の `markdown_to_word/assets/resume_template.docx` を基準に、書式付きの段落と表を複製し、Markdownの内容を挿入します。会社情報・職種別業務・スキルの行数は可変です。「【主な業務】」の箇条書きは「・」で表示し、固定改ページは複製しません。テンプレートが欠落・破損している場合は、異なるデザインへ自動切替せずエラーにします。テンプレートを選択するUIはありません。

**標準文書**は既存方式を維持します。A4縦、上下16mm、左右18mm、游ゴシック、本文10.5pt、行間1.15、本文段落後4pt、タイトル20pt、見出し1は13pt、見出し2は11.5pt、フッター中央にページ番号が従来の設定です。見出しの `keep_with_next`、短い表行の `cantSplit`、表ヘッダーの `tblHeader` の制御も維持します。

## Windows向けEXEをビルド

1. Windows 11 x64に**Python 3.13 x64**をインストールし、`py -3.13` を利用可能にします。
2. プロジェクトのルートで `build_release.bat` をダブルクリックするか、コマンドプロンプトで実行します。
3. 最小限のpytestに成功すると、PyInstallerによる`onedir`ビルドが実行されます。
4. `release\MarkdownToWord-0.1.0-win-x64.zip` が作成されます。

`onedir` 配布なので、ZIP内の EXE **だけを取り出さず**、フォルダー全体を展開して使います。Pythonの導入は配布先PCでは不要です。Microsoft Wordは生成に不要です。

## テスト

```bat
.venv\Scripts\python.exe -m pip install pytest==8.3.5
.venv\Scripts\python.exe -m pytest -q
```

対象は基本Markdown解析、Word構造、保存失敗時の既存ファイル保護、簡易GUI入力です。Windows 11実機での100%・125%・150%の画面操作は未検証です。CIのWindows環境による自動検証と実機の目視検証は別です。実際のWordのページ数やGUIのピクセル寸法を固定するテストは行いません。

## よくあるエラー

- **入力なし／空**：ファイルを選び直すかMarkdownを入力します。
- **UTF-8読み込み失敗**：元ファイルをUTF-8で保存し直します。
- **保存先不明**：存在するフォルダーを指定します。
- **Wordファイル使用中**：Word側で閉じてから再実行します。
- **入力が変更された**：再度「事前確認」を行います。
- **同名Wordがある**：置換、別名保存、キャンセルから選びます。

## 制限事項

- 動作は完全ローカル。外部通信、AI API、入力本文のログ化はありません。
- Wordファイルのページ数は実際のWord/LibreOffice側で確定します。Microsoft Wordとの表示差異があり得ます。
- HTML/CSS、複雑なセル結合、画像レイアウト、数式、脚注は高度な変換対象外です。HTMLやコードは実行されません。
- 高度なリストのネスト・番号形式、長い行の表分割、Web/ローカル画像の埋め込みは完全対応ではありません。
- 一括変換・PDF同時出力・Wordテンプレート取り込みは未対応です。
- **実際の応募書類や個人情報を公開GitHubリポジトリへコミットしないでください。** `docs/サンプル_架空.md` は架空の情報のみです。

## ディレクトリ

- `markdown_to_word/parser.py`：トークン解析と職務経歴書固有記法
- `markdown_to_word/models.py`：文書の中間モデル
- `markdown_to_word/docx_renderer.py`：スタイル別のWord出力振り分けと標準文書処理
- `markdown_to_word/resume_template.py`：職務経歴書専用のテンプレート描画
- `markdown_to_word/assets/resume_template.docx`：匿名化した職務経歴書の書式（同梱必須）
- `markdown_to_word/output.py`：検証付きの安全な保存
- `markdown_to_word/service.py`：2入力方式共通の処理
- `markdown_to_word/gui/`：Tkinter画面と非同期制御
- `tests/`：必要最小限のテスト
- `docs/使い方.md`：日本語ガイド
