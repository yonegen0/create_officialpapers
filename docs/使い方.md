# Markdown → Word 変換ツール｜使い方

## 1. 起動する

展開したフォルダーの `MarkdownToWord.exe` をダブルクリックします。Pythonから使う場合は `python -m markdown_to_word.gui` で起動できます。

## STEP 1：Markdownを入力する

**ファイルを選択**：`.md` `.markdown` `.txt` ファイルを1件または複数選びます。Ctrl/Shiftを使って複数選択できます。選択した件数とファイル名を一覧表示します。元ファイルと同じフォルダーが保存先の初期値になります。選択ダイアログをキャンセルしても直前の選択は保持します。

**直接貼り付け**：入力欄をクリックし、`Ctrl+V` で文章を貼ります。`Ctrl+A` 全選択、`Ctrl+C` コピー、`Ctrl+X` 切り取りも使えます。

入力方式を切り替えても、それぞれの内容は保持されます。変換されるのは現在選択中の入力方式だけです。

## STEP 2：Wordの出力設定

通常は「職務経歴書」を選びます。標準のMarkdownだけ使いたい場合は「標準文書」を選びます。1件または直接貼り付けの場合はファイル名を `.docx` 付きで入力します。2件以上の一括生成ではファイル名は元のMarkdown名から自動設定され編集できません。保存先フォルダーは全件共通です。

## STEP 3：事前確認・Word生成

メイン画面はヘッダー・フッター固定、中央の3ステップだけが縦スクロールします。フッターには処理状態・進捗・使い方・終了があります。画面幅に応じて設定欄と4指標が自動的に並び替わります。

### 事前確認する

「事前確認」をクリックすると、単体生成では文字数・見出し数・表数・箇条書き数・警告が表示されます。一括生成では選択数・生成可能数・エラー数・警告数と失敗理由をまとめて表示します。ここではWordは保存されません。

入力や文書スタイルを変更したら、もう一度事前確認してください。

### Wordを生成する

「Wordを生成」をクリックします。同じファイル名がある場合は「置換する」「別名で保存」「キャンセル」のいずれかを選択してください。保存失敗時は既存ファイルを削除しません。

**職務経歴書スタイルでは作成日を自動設定**します。Word生成時のPCローカル日付（`YYYY年M月D日現在`）がタイトルの後・氏名の前に入ります。冒頭の古い日付（年月のみの形式も含む）は置き換え、未記載でも挿入し、重複は1件にまとめます。単体・直接貼り付け・一括生成に共通して適用され、元のMarkdownや本文の日付は変更しません。事前確認後に日付が変わっても再確認は不要です。標準文書では日付を自動設定しません。

完了後、単体生成ではファイル名・保存先が表示されます。一括生成では成功・失敗件数とファイル別の結果が表示され、「保存先を開く」から作成されたWordを確認できます。\n\n**一括生成**：ファイルを2件以上選び事前確認を実行したら、「Wordを○件まとめて生成」を押してください。各ファイルを独立した `.docx` として保存します。既存ファイルと同名の場合は `(1)`、`(2)` の連番を自動設定し、上書きしません。読み込み失敗や事前確認後に変更されたファイルは失敗として扱い、他のファイルは生成します。テンプレートの欠落・破損や保存先の不備など共通エラーでは停止します。

入力ファイル・貼り付け本文・入力方式・文書スタイルを変更すると、4指標は未確認（—）に戻ります。出力ファイル名と保存先のみを変更した場合は事前確認をやり直す必要はありません。前回生成したWordファイルの参照は保持され、今回の入力に対する確認結果とは別に表示されます。生成失敗や保存キャンセルが新しい成功として表示されることはありません。

## 4. 職務経歴書の入力例

`docs/サンプル_架空.md` は架空の職務経歴書です。会社情報を2列表にする場合、次のように各行をタブまたは全角スペースで区切り、連続させてください。

```text
勤務先　架空製作所
在籍期間　2023年10月～現在
雇用形態　正社員
事業内容　製造業
会社規模　100名
```

`■ 職務経歴`、`① 来客対応`、`【主な業務】` や、職務経歴セクション内の `一般事務・受付（2023年10月～現在）` は見出しになります。末尾の独立した `以上` は右寄せします。

同じ列数のタブ区切り行が2行以上連続する場合も、職務経歴書スタイルで編集可能な表になります（通常の文章・リスト・引用・コードは対象外）。画像記法は埋め込まず、元のMarkdown文字列として保存して警告します。

## 5. 注意事項

- 入力本文を外部へ送信する機能はありません。
- 画像の埋め込みや高度なHTML変換は対象外です。
- WordとLibreOfficeでページの割り付けが多少変わる場合があります。
- 実際の応募書類は生成後にレイアウトと内容を確認してください。
- 同名ファイル確認はEscキーやウィンドウの×で安全にキャンセルできます。
- Windows 11実機での100%・125%・150%表示は未検証です。
