# 実装・検証結果（2026年11月13日）

## 実装した内容

- `markdown-it-py` トークンによるMarkdown解析と中間モデルへの変換
- 職務経歴書用のタイトル・日付・氏名、大見出し・小見出し、会社／スキル情報2列表
- `python-docx` による編集可能なWord、A4、日本語フォント、ページ番号、見出し制御
- 同名ファイル3択、一時ファイル保存と再読み込み検証、既存出力の保護
- Tkinter GUI（ファイル選択／直接貼り付け）、事前確認、ワーカースレッド生成、完了操作
- Windows 11 x64向けPyInstaller定義・バッチ・GitHub Actionsの最小CI

## 実行した検証

- Python 3.13.5 / Linux上の `python -m pytest -q` を実行（**18件成功・2件スキップ・0件失敗**。スキップはGUIディスプレイ不在によるもの）
- 仮想ディスプレイ下 `xvfb-run -a python -m pytest tests/test_gui.py -q` を実行し、ファイル選択・入力切替・事前確認・生成・Busy制御・完了通知の2件が成功
- 仮想ディスプレイ上でGUIを起動し、直接貼り付け → 事前確認 → Word生成完了まで実行
- 架空サンプルMarkdownを実際にWord出力し、python-docxで読み直しを確認
- LibreOfficeを用いて生成Wordをページ画像にレンダリングし、ページ画像を目視確認
- 生成したWordについて、本文・表・箇条書き・ページ番号・文字化け・見出しの配置を確認

## 確認していないこと

- Windows 11でのPyInstaller EXEビルドと起動確認（Windows実行環境がないため）

- GitHub `markdown_to_word` へのPR/CI/mainマージ（新規リポジトリがまだ存在せず、作成APIも利用不可のため）

## 制限

- LibreOfficeによる見た目とMicrosoft Wordでの表示には差異があります。
- レイアウトは実文書の長さによって変わり、ページ数を固定する実装ではありません。
- OSでの本番配布テストを完了したという意味ではありません。
